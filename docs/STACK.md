# Силуэт 360 — технический стек

Цель продукта: снять человека по кругу (360°) телефоном, получить точную 3D-модель тела
с мерками и выдать её в вебе/AR/для экспорта.

## Конвейер

```
Телефон (съёмка 360°) ──► API ──► очередь ──► GPU-воркеры ──► хранилище ──► веб/AR-просмотр
   кадры + глубина        загрузка   задачи    реконструкция    GLB/USDZ      Three.js
```

## Рекомендуемый стек

| Слой | Выбор | Почему |
|---|---|---|
| Мобильный клиент | **Swift + ARKit** (iOS), **Kotlin + ARCore** (Android); на старте — только iOS | Нужен доступ к LiDAR/depth, позам камеры и контролю экспозиции. Кросс-платформенные фреймворки (Flutter/React Native) дают это только через нативные мосты. |
| Гид съёмки | ARKit body tracking + собственный UI «обойдите по кругу», 36 кадров с шагом 10° | Пользователь видит, какие ракурсы ещё не сняты (как в прототипе). |
| API | **Python + FastAPI**, загрузка напрямую в S3 по presigned URL | Весь ML-стек на Python, один язык для API и воркеров. |
| Очередь задач | **Redis + Celery** на старте, **Temporal** при росте | Многошаговый долгий конвейер с повторами. |
| 3D по фото (прототип) | В браузере: отделение фона по краям кадра → visual hull на воксельной сетке → цвет из ближайшего по ракурсу фото → мерки по срезам | Работает без сервера, но требует однотонного фона и даёт только «оболочку» без вогнутостей. В продукте заменяется строками ниже. |
| Сегментация | **SAM 2** | Чистая маска человека на каждом кадре. |
| Поза / ключевые точки | **ViTPose** или **MediaPipe Pose** | Начальное приближение для подгонки модели. |
| Параметрическая модель тела | **SMPL-X** (подгонка формы и позы) | Даёт топологию с риггингом и честные мерки по поверхности. Лицензия SMPL-X некоммерческая — для продукта нужна коммерческая лицензия (Meshcapade) или открытая альтернатива. |
| Детальная геометрия и текстура | **3D Gaussian Splatting** (gsplat / nerfstudio) поверх SMPL-X | Фотореалистичный вид одежды и волос; параметрическая модель остаётся «скелетом» для мерок. |
| Хранилище | **S3-совместимое** (AWS S3 / Cloudflare R2) + **PostgreSQL** | Файлы моделей отдельно, метаданные и мерки в БД. |
| GPU-инфраструктура | **Modal** или **RunPod** на старте, затем Kubernetes + GPU-ноды | Платите только за время обработки скана. |
| Веб-просмотр | **React + react-three-fiber + drei** (Three.js), для сплатов — **Spark** или `@mkkellogg/gaussian-splats-3d` | Тот же движок, что в прототипе; работает в мобильном браузере. |
| AR | **USDZ** → AR Quick Look (iOS), **GLB** → Scene Viewer (Android) | Нативный AR без своего приложения. |
| Позы | Скелет SMPL-X (55 суставов) + библиотека поз в JSON; для продукта — датасет AMASS (лицензия) или собственная съёмка; позы ставятся вращением суставов, своя поза сохраняется в БД пользователя | В прототипе — упрощённый скелет из 13 суставов с тем же принципом. |
| Форматы экспорта | GLB (основной), USDZ, OBJ, JSON с мерками | GLB понимают все движки и веб. |

## Этапы

1. **MVP (этот прототип):** параметрическая модель, обзор 360°, мерки — без съёмки.
2. **Скан v1:** iOS-приложение, 36 кадров + LiDAR → SMPL-X → мерки ±2 см.
3. **Скан v2:** Gaussian Splatting для реалистичного вида, Android.
4. **Интеграции:** API для магазинов одежды (размерная сетка), фитнес-трекинг изменений тела.
