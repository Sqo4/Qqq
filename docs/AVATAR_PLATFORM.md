# Силуэт 360 → ИЛ: HD-аватар и искусственная личность для соцсетей

Цель: человек снимает себя по кругу, получает HD-модель лица и тела, а из неё —
аватарки, стикеры, видеоаватар и «искусственную личность» (ИЛ) для всех соцсетей и мессенджеров.

## Что уже есть в прототипе (`prototype/index.html`)

| Возможность | Как сделано | Ограничение |
|---|---|---|
| Тело по меркам + 59 поз | Параметрическая модель на скелете из 13 суставов | Упрощённая геометрия, лицо схематичное |
| 3D по 30–60 фото | Visual hull в браузере, цвет из фото | Без вогнутостей, нужен однотонный фон, не HD |
| Аватарки для 12 сетей | Рендер модели в 7 стилях, фон, кадр, поворот, PNG под размер сети | Стиль задаётся материалами, не нейросетью |
| Стикеры | 6 поз, прозрачный фон, белая обводка, 512×512 | PNG; для WhatsApp нужен WebP |
| ИЛ | Claude пишет био под каждую сеть, приветствие, стиль речи, подписи к стикерам; чат с ИЛ | Нет памяти и голоса |
| Экспорт | ZIP: аватарки, стикеры, `persona.json`, инструкция | — |

## HD-модель: что нужно на сервере

HD в браузере не получить: нужны нейросети на GPU (минуты на один скан).

```
Съёмка ─► Предобработка ─► Тело (SMPL-X) ─► Лицо (FLAME) ─► Внешний вид (3DGS) ─► Риг ─► Рендер/стилизация ─► Пакет для сетей
```

1. **Съёмка.** Видео 30–60 с по кругу (из него берутся 100–200 кадров) + 20–30 крупных фото лица с разных сторон. На iPhone — данные LiDAR и позы камеры из ARKit.
2. **Предобработка.** SAM 2 — маска человека и волос; позы камер — COLMAP/GLOMAP или ARKit; ключевые точки тела и лица — ViTPose и детектор лица.
3. **Тело.** Подгонка SMPL-X (форма, поза, руки) по маскам и точкам. Даёт скелет, мерки, анимацию.
4. **Лицо.** Подгонка FLAME (форма головы, выражения, блендшейпы под 52 выражения ARKit) по крупным фото.
5. **Внешний вид в HD.** Гауссовы сплаты (3D Gaussian Splatting), привязанные к SMPL-X и FLAME (подход GaussianAvatars и аналогов): фотореалистичные кожа, волосы, одежда, и при этом модель анимируется. Плюс запечённая mesh-версия с текстурами 4K для движков и AR (GLB/USDZ).
6. **Риг и выражения.** Скелет от SMPL-X, лицо — блендшейпы FLAME. Позы берутся из той же библиотеки, что в прототипе.
7. **Рендер и стилизация.** HD-модель рендерится в нужной позе и ракурсе → карты глубины, позы и нормалей → диффузионная модель с ControlNet и адаптером идентичности дорисовывает стиль (аниме, комикс, масло, киберпанк), сохраняя похожесть. 3D-модель даёт согласованную позу и ракурс, нейросеть — художественный стиль.
8. **Пакет.** Аватарки под размеры сетей, стикеры (WebP для WhatsApp, PNG/WebM для Telegram), видеоаватар (короткое зацикленное видео с поворотом головы), `persona.json`.

**Лицензии проверить до запуска.** SMPL-X и FLAME бесплатны только для некоммерческого использования (коммерческая лицензия — через Meshcapade/MPI). У части моделей идентичности (например, на основе insightface) веса тоже некоммерческие.

## Видео, нейро-изображения и голос

| Модуль | В прототипе | На сервере (продукт) |
|---|---|---|
| Видео по кругу | Подсказка съёмки на 3D-сцене; из видео берутся 36–72 кадра и идут в тот же конвейер, что фото | Все кадры видео + позы камеры (COLMAP/ARKit) → SMPL-X/FLAME + 3DGS; видео даёт больше ракурсов и лучшее совмещение, чем отдельные фото |
| Изображение в нейросети | Референс-рендер, карта глубины и скелет OpenPose из модели (кадры совпадают), промпт от Claude, ZIP для ComfyUI/Automatic1111/Midjourney | SDXL или Flux + ControlNet (OpenPose + Depth) + адаптер идентичности (IP-Adapter FaceID / InstantID) по фото пользователя; генерация в очереди на GPU |
| Голос | Загрузка речи до 30 минут, проверка качества (громкость, шум, перегруз), высота и темп голоса, профиль голоса; предпросмотр голосом браузера с движением губ модели | Расшифровка Whisper → обучение/дообучение TTS-модели (XTTS v2, F5-TTS или коммерческий сервис) → голос ИЛ для ответов, видео и кружков; синхронизация губ по фонемам |

Голос, как и лицо, — биометрия: нужно отдельное согласие, проверка, что голос принадлежит владельцу аккаунта, и запрет на клонирование чужих голосов.

## ИЛ — искусственная личность

- **Профиль** (`persona.json`): имя, слоган, черты, стиль речи, био под каждую сеть, приветствие, хэштеги, подписи стикеров. В прототипе его пишет Claude.
- **Память.** Факты о человеке и его темах хранятся в БД (PostgreSQL + векторный поиск), подмешиваются в запрос к модели.
- **Генерация.** Claude (API Anthropic) — био, посты, ответы в чате в голосе ИЛ.
- **Голос (опционально).** Синтез речи с клоном голоса — только по явному согласию владельца голоса.
- **Правило прозрачности.** ИЛ не выдаёт себя за живого человека, если её прямо спрашивают; контент от ИЛ помечается.

## Доставка в соцсети и мессенджеры

| Канал | Что реально можно | Как |
|---|---|---|
| Telegram | Набор стикеров, бот с ИЛ, мини-приложение | Bot API (`createNewStickerSet`), Telegram Mini App с этим же интерфейсом |
| WhatsApp | Набор стикеров, бот с ИЛ | Стикеры — WebP 512×512 через приложение-пак; бот — WhatsApp Business Platform |
| ВКонтакте | Бот сообщества с ИЛ, мини-приложение | VK API, VK Mini Apps |
| Instagram, TikTok, X, YouTube, LinkedIn, Facebook | Аватарка и био | Пользователь загружает сам: API этих сетей не дают сторонним приложениям менять аватар профиля |
| Discord | Бот с ИЛ, аватар | Discord API |

Итого продукт = веб/мини-приложение (создание) + пакет файлов (загрузка руками) + боты ИЛ в мессенджерах, где боты разрешены.

## Безопасность и закон

- **Только своё лицо.** Проверка живости (liveness) при съёмке и сверка лица на фото с лицом владельца аккаунта, чтобы нельзя было сделать аватар чужого человека.
- **Биометрия.** Фото и 3D-модель лица — биометрические персональные данные. По 152-ФЗ нужно отдельное письменное согласие, хранение данных граждан РФ — на серверах в РФ. Для пользователей из ЕС — GDPR. Перед запуском — консультация юриста.
- **Удаление.** Кнопка «удалить все мои данные»: сырые фото удаляются после построения модели, модель — по запросу.
- **Маркировка.** ИИ-контент помечается в метаданных (C2PA) и в профиле ИЛ.

## Этапы

1. **Сейчас — прототип:** весь путь от тела до пакета для сетей и ИЛ, без HD.
2. **MVP HD (1):** сервер с SMPL-X + FLAME + 3DGS, съёмка видео по кругу, экспорт аватарок и стикеров из HD-модели.
3. **Стили:** стилизация через диффузию с сохранением похожести.
4. **ИЛ в мессенджерах:** боты Telegram и VK, память, видеоаватар.
5. **Голос и анимация:** говорящий аватар для кружков и видео.
