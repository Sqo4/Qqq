# База знаний почтового бота

Бот ведёт деловую переписку по e-mail (РФ) от имени компании: заборы, ворота, мебель лофт.

## Как это работает

1. **Интервью.** Директор надиктовывает ответы по сценарию `01_сценарий_интервью.md`
   (7 блоков по 15–25 минут).
2. **Записи.** Аудио или текстовые расшифровки кладутся в папку `записи/`
   (`блок_1.m4a`, `блок_1.txt` и т.д.).
3. **Обработка.** Ответы раскладываются по разделам `02_база_знаний.json`:
   разговорная речь превращается в короткие готовые ответы для писем,
   к каждому вопросу добавляются варианты формулировок клиента.
4. **Проверка.** Директор вычитывает итог: всё ли верно, нет ли лишних обещаний.
5. **Подключение.** JSON загружается в бота (как контекст или как источник для поиска).

## Файлы

| Файл | Что это |
|---|---|
| `01_сценарий_интервью.md` | Вопросы для директора и правила записи |
| `02_база_знаний.json` | Структура базы знаний (заполняется по интервью) |
| `записи/` | Аудио и расшифровки интервью |
