# Сайт-портфолио

Статический личный сайт на чистых HTML, CSS и JS — без сборки и зависимостей.

## Структура

- `index.html` — разметка и контент
- `styles.css` — стили (светлая и тёмная темы, адаптив)
- `script.js` — переключение темы, мобильное меню, фильтр проектов, форма

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

## Что поменять под себя

- Имя, тексты и цифры в `index.html`
- Карточки проектов в разделе `#projects`
- Контакты: `hello@example.com`, ссылки на Telegram и GitHub (также адрес в `script.js`)

## Публикация

Подойдёт GitHub Pages: Settings → Pages → Deploy from branch → выберите ветку и корневую папку.
