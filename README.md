# Сайт Владимира

Одна платформа из четырёх частей:

| Адрес | Что там |
|---|---|
| `/` | Главная: нарисованная комната, человечек-программист с котом, достижения и приз |
| `/cases` | О создателе: кейсы, услуги, благодарности, форма заявки |
| `/learn` | Обучалка по ИИ: 3 блока — знакомство с ИИ, взаимодействие с ИИ, MVP с защитой для деплоя |
| `/app` | Сообщество: знакомства студентов и предпринимателей с ручной проверкой анкет |
| `/admin` | Модерация: проверка анкет, жалобы, заявки с сайта |

Сервер — один файл `server.js` на Node.js без внешних зависимостей (встроенные `node:http` и `node:sqlite`).

## Запуск локально

Нужен Node.js 22.13 или новее.

```bash
npm run dev        # демо-профили + ключ модератора dev-admin
# открыть http://localhost:8080
```

`npm run dev` создаёт четыре проверенных демо-профиля, которые отвечают взаимностью: так сразу видно мэтч и чат. В продакшене его не используйте.

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `PORT` | порт, по умолчанию 8080 |
| `DATA_DIR` | где хранить базу и фото, по умолчанию `./data` |
| `ADMIN_TOKEN` | ключ входа в `/admin` (длинная случайная строка). Без него модерация выключена |
| `SECURE_COOKIES=1` | ставить cookie только по HTTPS — включить в продакшене |
| `TRUST_PROXY=1` | брать IP из `X-Forwarded-For`, если сервер стоит за nginx/Caddy |
| `SEED_DEMO=1` | демо-профили (только для разработки) |

## Деплой

Подойдёт любая VPS или облако с постоянным диском. Персональные данные граждан РФ нужно хранить в России, поэтому лучше Yandex Cloud, Selectel или VK Cloud.

```bash
docker build -t vladimir-site .
docker run -d --name site -p 8080:8080 -v site-data:/data \
  -e ADMIN_TOKEN="$(openssl rand -hex 24)" -e SECURE_COOKIES=1 -e TRUST_PROXY=1 vladimir-site
```

Перед сервером поставьте Caddy или nginx с HTTPS (Caddy получает сертификат сам). Делайте бэкап тома `/data` по расписанию.

## Как устроена защита

- Пароли хранятся только в виде хеша scrypt; вход и регистрация ограничены по частоте.
- Сессии в cookie `HttpOnly` + `SameSite=Lax`; у модератора отдельная cookie.
- Изменяющие запросы принимаются только со своих страниц (заголовок `X-Requested-With` + проверка `Origin`).
- Загружаются только картинки (проверка по содержимому, до 1,5 МБ); браузер сжимает фото и убирает из них EXIF.
- Фото профилей видят только проверенные участники. Фото с документом видит только модератор, и файл удаляется сразу после решения.
- Заголовки безопасности: CSP, `nosniff`, `X-Frame-Options`, `Referrer-Policy`.
- Лимиты на сообщения, жалобы и загрузки; 10 анкет в день на человека.

## Что заполнить

На `/cases` в квадратных скобках стоят заглушки: результаты по кейсам, описание софта для СПбГУ, текст «Обо мне», остальные благодарности, Telegram и почта. Тексты уроков — в `public/learn/course.js`.
