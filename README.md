# Сайт Владимира: «Человечки»

Личный сайт на одной странице: бумажный фон и нарисованный от руки человечек, который пишет код в своей комнате, с котом. С ним можно играть: пинать, подкидывать, кликать по вещам в комнате, собирать достижения. За все достижения посетитель получает бесплатную 20-минутную консультацию.

Всё в одном файле `index.html`: canvas-анимация, звуки (встроены как data-URI) и стили. Сборка и зависимости не нужны, только шрифты с Google Fonts.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

## Звуки

- Записи ударов, грохота, стука и монетки: стартовые наборы Kenney (CC0).
- Звуки интерфейса (клавиши, щелчок, достижение, ошибка, уведомление): uisfx (CC0).
- Мяуканье, мурлыканье, шипение, свист, гром, стекло и т. п.: синтезированы для этого сайта.
