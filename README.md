# Сайт музыканта с живой гитарой

Одностраничный сайт: на «рабочем столе» лежит гитара, на которой можно играть прямо в браузере.
Звучат записи настоящей акустической гитары: отдельная запись на каждый полутон, всё лежит в `samples.js`.
Пока записи загружаются (доли секунды), работает синтез по алгоритму Карплуса — Стронга.

## Как играть
- **Лады** — нажмите на гриф, палец прижмёт струну. Повторное нажатие отпускает.
- **Струны** — проведите мышью поперёк струн над корпусом (можно без нажатия) или пальцем на телефоне.
- **Заглушить струну** — нажмите у порожка или на ноту справа от подставки.
- **Карточки аккордов** — Am, Dm, E, C, G, F, Em, A, D, B7.
- **Клавиатура:** `1`–`0` аккорды, `Пробел`/`↓` удар вниз, `↑` вверх,
  `A S D F G H` отдельные струны, `B` бой, `P` перебор, `Esc` отпустить всё.
- На телефоне в портретной ориентации гитара встаёт вертикально.

## Варианты оформления
Внизу слева есть переключатель: «Стол», «Сцена», «Винил», «Галерея». Вариант можно открыть сразу
по ссылке с якорем: `index.html#stage`, `#vintage`, `#gallery`, `#desk`. Когда вариант выбран, переключатель
(блок `look-switch` в `index.html`) можно удалить, а нужный вариант вписать в начальный скрипт.

## Файлы
- `index.html` — разметка и тексты. Первый экран — портрет и имя музыканта, ниже гитара, затем «О себе»,
  музыка, концерты, контакты (замените заглушки и вставьте фото вместо `photo-placeholder`).
- `style.css` — оформление стола и разделов.
- `guitar.js` — гитара, звук, аккорды (список `CHORDS` легко дополнить).
- `samples.js` — записи гитары (mp3 в base64, ~1,9 МБ). Источник: University of Iowa Electronic Music Studios
  (свободное использование), подготовлены в проекте [tonejs-instruments](https://github.com/nbrosowsky/tonejs-instruments) (MIT).

## Запуск
Достаточно открыть `index.html` в браузере. Для публикации подойдёт GitHub Pages:
Settings → Pages → Deploy from branch.
