# Translate Bot

Мини-бот для Telegram: переводит **текст, голосовые, аудио и кружочки** из диалога.

- Работает в паре языков (по умолчанию `ru ⇄ en`): бот сам определяет язык и переводит на второй.
  Удобно для переписки двух людей на разных языках — в личке или в группе.
- Речь распознаётся локально через [faster-whisper](https://github.com/SYSTRAN/faster-whisper) (бесплатно, без API-ключей).
- Перевод — Google Translate через [deep-translator](https://github.com/nidhaloff/deep-translator) (бесплатно, без ключа).
- **Выжимка диалога** (`/summary`) через Claude API: суть, участники и их позиции, задачи
  (кто и к какому сроку), варианты решения с выгодами ➕ и рисками ⚠️, принятое решение и открытые вопросы.
  Можно переслать боту сообщения из любого чата — он учтёт исходных авторов.

## Как сделать выжимку переписки

1. Откройте нужный чат в Telegram.
2. Зажмите одно сообщение → «Выбрать», отметьте остальные (можно 100 и больше).
   На компьютере: кликните сообщение и протяните выделение / Shift+клик.
3. «Переслать» → выберите бота.
4. Подождите несколько секунд — бот сам пришлёт выжимку: суть, участники, задачи,
   варианты решения с выгодами ➕ и рисками ⚠️, решение и открытые вопросы.

Пересланные голосовые тоже распознаются и учитываются.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
   Для групп: `/setprivacy` → `Disable`, чтобы бот видел все сообщения.
2. Нужны Python 3.10+ и `ffmpeg`.

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export BOT_TOKEN=123456:ABC...
export ANTHROPIC_API_KEY=sk-ant-...   # для /summary, ключ: https://console.anthropic.com
python bot.py
```

Переменные окружения (необязательные):

| Переменная      | По умолчанию | Описание                                             |
|-----------------|--------------|------------------------------------------------------|
| `WHISPER_MODEL` | `small`      | `tiny`/`base` — быстрее, `medium`/`large-v3` — точнее |
| `DEFAULT_PAIR`  | `ru,en`      | Пара языков по умолчанию (выжимка — на первом языке) |
| `HISTORY_LIMIT` | `500`        | Сколько последних сообщений чата помнить для выжимки |
| `BATCH_IDLE`    | `8`          | Сколько секунд тишины ждать после пересылки, прежде чем делать выжимку |

## Команды

- `/start` — справка и текущая пара языков
- `/pair ru de` — сменить пару языков для этого чата
- `/summary` — выжимка диалога: суть, задачи, варианты решения, выгоды и риски
- `/clear` — очистить историю и начать новый диалог

История хранится в памяти и сбрасывается при перезапуске бота.
