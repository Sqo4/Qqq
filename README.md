# Силуэт 360

Прототип 3D-моделирования человека с обзором 360°.

- `prototype/index.html` — интерактивный прототип (Three.js): параметрическая модель тела, вращение камеры на 360°, ракурсы, обхваты, таблица мерок, симуляция скана. Откройте файл в браузере — сборка не нужна.
- `docs/STACK.md` — рекомендуемый технический стек и этапы.

Управление: перетаскивание — вращение, колесо или щипок — масштаб.
