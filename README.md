# Силуэт 360

Прототип 3D-моделирования человека с обзором 360°.

- `prototype/index.html` — интерактивный прототип (Three.js): параметрическая модель тела со скелетом из 13 суставов, вращение камеры на 360°, ракурсы, библиотека из 59 поз (базовые, повседневные, спорт, йога, эмоции), редактор своей позы с сохранением и обменом через JSON, обхваты, таблица мерок и построение 3D по 30–60 фото: отделение человека от фона, вырезание объёма по силуэтам (visual hull), раскраска по фото, снятие мерок и подгонка модели. Кнопка «Демо» сама снимает 50 фото с модели и сравнивает результат с эталоном. Откройте файл в браузере — сборка не нужна.
- `docs/STACK.md` — рекомендуемый технический стек и этапы.

Управление: перетаскивание — вращение, колесо или щипок — масштаб.
